# 시험지출력기

`시험지출력기.html` **한 장이면 끝난다.** 더블클릭 → 브라우저 → `새 시험지` → `인쇄`.
인터넷도, 우리 서버도, 다른 파일도 필요 없다 — 문제은행이 파일 안에 들어 있다.

## 매장에 전달하는 법

- **메일 첨부** — 받은 사람이 내려받아 더블클릭하면 그대로 열린다.
  회사 메일 게이트웨이가 HTML 첨부를 걷어내면 **zip 으로 압축해** 보낸다
  (Gmail·Outlook 은 `.html` 첨부를 막지 않는다).
- **USB·카카오톡 파일** — 같다. 옮긴 자리에서 그대로 동작한다.

## 쓰는 법

| | |
|---|---|
| **새 시험지** | 문제은행에서 20문항을 랜덤으로 뽑는다. 누를 때마다 다른 시험지다 (은행 문항 수는 화면이 밝힌다) |
| **인쇄** | A4 4장 — 시험지 2장 + 정답·해설 2장 |
| **PDF 로 남기려면** | 인쇄창에서 **대상**을 **"PDF로 저장"** 으로 고른다. 파일 이름에 시험지 코드가 붙는다 |
| **문항 / 정책 %** | 5~50문항, 정책 문항 비율. 정책 문항이 모자라면 그 사실을 화면이 밝힌다 |
| **코드** | 오른쪽 위 네 글자. **같은 코드를 넣으면 같은 시험지가 다시 나온다** |

**시험지 코드를 반드시 확인할 것.** 매번 다른 문제가 나오므로 여러 장 인쇄하면
시험지와 정답지가 섞인다 — 두 장 머리의 코드가 같아야 짝이다.
채점할 때 코드를 넣으면 그 시험지를 그대로 다시 뽑을 수 있다.

## 이 파일을 고치려면

**직접 고치지 말 것 — 빌드 결과물이다.** 다음 빌드에서 덮어써진다.

```
npm run build:examtool     # scripts/exam-print-template.html + 문제은행 → 이 파일
npm run test:examtool      # 신선도 · 자립성 · 실물(file:// 로 열어 본다)
```

- 화면·조판을 고치려면 → `scripts/exam-print-template.html`
- 문항을 고치려면 → `public/test-app.html` 의 `QB` (레벨업 챌린지와 **같은 은행**이다)
- **문항을 늘렸으면 빌드를 다시 돌려 커밋할 것.** 안 하면 매장에 나간 파일이 옛 문항으로
  굳는데 화면에는 아무 표시도 안 난다. `test:examtool` 이 그것을 잡는다.
