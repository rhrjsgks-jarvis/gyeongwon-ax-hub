# 실제 도면 코퍼스 — 로컬에서 모아 넣는 곳

`scripts/fixtures/plans.mjs`의 합성 평면은 **표기 관례**를 재현한 것이라 "이런 유형에서 깨지지
않는다"까지만 보증한다. 진짜 도면에서 어디가 깨지는지는 진짜 도면으로만 알 수 있다.

이 폴더에 도면 이미지를 넣고 `index.json`에 "여기를 누르면 몇 ㎡가 나와야 한다"를 적으면
`npm run test:plans`가 합성 평면과 함께 전수 검사한다.

## 왜 로컬에서만 모으는가

클라우드 세션(Claude Code on the web)은 프록시가 외부 호스트 접속을 막는다 — `curl`이
`CONNECT tunnel failed, response 403`으로 끊긴다. samsung.com·lh.or.kr 전부 마찬가지다.
설치환경 가이드 이미지를 모을 때(PR #54)도 같은 이유로 **로컬 cmd 세션**에서 진행했다.
도면 수집도 같은 방식으로 하면 된다.

## 로컬 세션에서 할 일

로컬 Claude Code(cmd)에 이 저장소를 열고 아래를 그대로 시키면 된다.

```
경원 AX 허브 저장소에서 배치 시뮬레이터 도면 코퍼스를 채워줘.

1. 아래 출처에서 아파트 평면도 이미지를 10~15장 내려받아
   scripts/fixtures/plans-real/ 에 저장해줘. 파일명은 출처-타입.png 형식으로.
   - LH 청약플러스 하나로 (hanaro.lh.or.kr) 타입별 평면도
   - 각 건설사 분양 사이트의 타입별 평면도 (롯데캐슬·자이·힐스테이트 등)
   - 확장형/비확장형, 판상형/타워형, 59·74·84·101타입을 섞어서
   - 컬러 렌더링본과 흑백 선도면을 둘 다 포함할 것

2. 각 도면마다 브라우저로 gyeongwon-ax-hub.vercel.app/place 를 열어
   도면을 올리고 축척을 맞춘 뒤, 방을 눌러 나오는 넓이를 확인해줘.

3. 도면에 적힌 실제 치수(예: 침실1 3,600×3,300)로 계산한 넓이와 비교해서
   scripts/fixtures/plans-real/index.json 에 항목을 추가해줘. 형식은
   index.example.json 참고. atPx는 이미지 픽셀 좌표, areaM2는 기대 범위다.

4. npm run test:plans 를 돌려 어떤 도면에서 어떻게 어긋나는지 결과를 정리해줘.
```

## index.json 형식

```json
[
  {
    "file": "lh-84A.png",
    "mmPerImgPx": 7.35,
    "note": "LH 인천가정2 B2 84A · 확장형",
    "probes": [
      { "atPx": [640, 420], "areaM2": [44, 56], "label": "거실+주방(트임)" },
      { "atPx": [280, 380], "areaM2": [13, 18], "label": "침실1 3,200×5,000" }
    ]
  }
]
```

| 항목 | 뜻 |
|---|---|
| `file` | 이 폴더 안의 이미지 파일명 |
| `mmPerImgPx` | 도면 이미지 1px이 몇 mm인가. 도면의 치수선 두 점 사이 픽셀 거리와 적힌 치수로 구한다 (`실제mm ÷ 픽셀거리`) |
| `probes[].atPx` | 누를 지점 (이미지 픽셀 좌표) |
| `probes[].areaM2` | 기대 넓이 범위 `[최소, 최대]`. **도면에 적힌 치수로 계산한 값**에 ±10% 정도 |
| `probes[].label` | 무슨 방인지 (실패 메시지에 함께 나온다) |

**기대값은 반드시 도면에 적힌 치수로 계산한다.** 앱이 내놓은 값을 그대로 적으면 검사가
아무것도 지키지 못한다.

## 이미지 파일은 커밋하지 않는다

이 저장소는 public이라 분양 도면 이미지를 올리면 저작권 문제가 된다. `.gitignore`가
이미지 파일을 걸러 내고 `index.json`만 커밋된다(치수 숫자만 들어 있다). 그래서 CI에서는
이 폴더가 비어 자동으로 건너뛰고, **로컬에서 이미지를 가진 사람만** 실제 도면 검사가 돈다.

파일이 없으면 `npm run test:plans`가 이렇게 알린다:

```
SKIP: 실제 도면 3벌이 index.json에 있지만 파일이 없습니다 (public repo라 이미지는 커밋하지 않습니다)
```
