# 도면 라이브러리 — 지역 → 아파트 → 타입

배치 시뮬레이터의 **도면 불러오기** 버튼이 읽는 곳이다. 상담 현장에서 도면을 매번 찾아
올릴 수는 없으니, 담당 지역 아파트 도면을 미리 모아 두고 세 번만 눌러 불러온다.

- 목록: `public/plan-library.json`
- 이미지: `public/plans/<파일명>`

축척이 확인된 도면은 **축척 맞추기를 건너뛰고 바로 벽 인식까지** 간다.

## `plan-library.json` 형식

```json
[
  {
    "region": "경기 남양주",
    "apt": "다산자이 아이비플레이스",
    "note": "2026-03 입주 · 1,614세대",
    "types": [
      { "name": "84A (확장형)", "file": "gg-namyangju-dasan-jaie-84A.png", "mmPerImgPx": 7.35 },
      { "name": "74B",          "file": "gg-namyangju-dasan-jaie-74B.png", "mmPerImgPx": 8.10 },
      { "name": "59C",          "file": "gg-namyangju-dasan-jaie-59C.png" }
    ]
  }
]
```

| 항목 | 뜻 |
|---|---|
| `region` | 지역. 드롭다운 1단. **경원영업팀 담당 지역**(경기 17개 시 + 강원 18개 시·군) 기준으로 `경기 OO시` / `강원 OO시` 형태로 통일 |
| `apt` | 아파트명. 드롭다운 2단 |
| `note` | 입주 시기·세대수 등. 선택 화면에 함께 뜬다 (생략 가능) |
| `types[].name` | 평형·타입. 드롭다운 3단 (`84A (확장형)`처럼 확장 여부까지 적으면 좋다) |
| `types[].file` | `public/plans/` 안의 파일명 |
| `types[].mmPerImgPx` | 도면 이미지 1px이 몇 mm인가. **생략하면** 앱이 축척 맞추기 단계를 띄운다 |

## `mmPerImgPx` 구하는 법 — 추측하지 말 것

도면에 적힌 치수선 하나를 골라 **두 끝점의 픽셀 거리**를 재고:

```
mmPerImgPx = 도면에 적힌 실제 mm ÷ 픽셀 거리
```

예: 치수선에 `3,600`이라 적혀 있고 두 끝점이 490px 떨어져 있으면 `3600 ÷ 490 = 7.35`.

**확신이 없으면 비워 둔다.** 비어 있으면 앱이 축척 맞추기를 띄우고, 사용자가 화면에서
치수선 두 점을 눌러 직접 확정한다. 틀린 축척을 넣으면 모든 치수가 틀어져 상담에서
바로 사고가 난다 — 설치환경 가이드 이미지 원칙과 같다.

## 수집할 때 — 치수가 적힌 도면만

- **치수선이 있는 도면만** 담는다. 치수 없는 렌더링 이미지는 축척을 확정할 수 없어 쓸모없다.
- 확장형/비확장형이 따로 있으면 둘 다 담고 `name`에 표기한다.
- 같은 아파트에 타입이 여러 개면 `types[]`에 나열한다.
- 파일명은 `지역-아파트-타입.png` 형태로 통일한다 (한글 파일명은 피한다).

## 저작권

분양 도면은 시행사·건설사 자료다. **사내 영업 지원 용도로만** 쓰고 외부 배포·재판매는
하지 않는다. 이 저장소는 public이므로 이미지를 커밋하기 전에 아래 중 하나를 정할 것:

1. **커밋한다** — 배포된 앱에서 바로 쓸 수 있다. 대신 도면이 공개 저장소에 남는다.
2. **커밋하지 않는다** — `.gitignore`에 `public/plans/*.png` 등을 추가한다. 이 경우
   Vercel 배포본에는 도면이 없어 라이브러리가 비어 보인다(파일 업로드는 그대로 된다).

기본값은 **2번(커밋하지 않음)** 이다. 1번으로 갈지는 사용 범위를 확인한 뒤 정한다.

## 로컬 세션에 붙여넣을 지시문

```
경원 AX 허브 저장소에서 도면 라이브러리를 채워줘.

대상: 경원영업팀 담당 지역 = 경기도 17개 시 + 강원도 18개 시·군.
그중 2026~2027년 입주 예정 아파트를 우선으로, 단지당 대표 타입 1~3개.

1. 각 단지의 **치수가 적힌** 타입별 평면도를 찾아 public/plans/ 에
   지역-아파트-타입.png 형식으로 저장해줘. 치수선이 없는 이미지는 건너뛰어.

2. 각 도면에서 치수선 하나의 픽셀 거리를 재서 mmPerImgPx = 적힌mm ÷ 픽셀거리 로
   계산하고, public/plan-library.json 에 region / apt / note / types[] 를 채워줘.
   계산이 애매하면 mmPerImgPx를 비워 두고 넘어가. 추측값을 넣지 말 것.

3. npm run build 로 빌드가 깨지지 않는지 확인하고,
   몇 개 단지·타입이 등록됐는지 지역별로 정리해줘.
```
