# 매장 전광판 — 호출 음성안내 (2026-08-30 사장님 요청)

> *"컨시어지에서는 매장전광판에 고객이 호출되었을때 호출된 번호를 읽어주고
> `000번 고객님 상담이 가능합니다` 라는 멘트를 2번 진행해주면 좋겠습니다.
> 음성안내기능 넣을 수 있습니까?"*

**됩니다.** 브라우저에 들어 있는 음성합성(Web Speech API)을 씁니다 — 음성 파일도, 외부
서비스도, 추가 비용도 없습니다.

전광판 소스는 **이 저장소가 아니라 Apps Script 쪽**에 있습니다(쿠폰과 같은 상황). 아래
조각을 전광판 HTML 의 `<script>` 안에 붙여 넣으면 됩니다.

---

## 먼저 — 실물로 확인한 것 (2026-08-30)

붙이기 전에 **정말 되는지**부터 쟀습니다. Apps Script 는 우리 HTML 을
`googleusercontent.com` 의 **중첩 iframe**(`sandbox="allow-scripts allow-same-origin …"`)
안에서 돌리기 때문에, 겉 지면에서 된다고 안에서도 된다는 보장이 없습니다.

| 잰 것 | 결과 |
|---|---|
| 샌드박스 안에서 `speechSynthesis` 가 사는가 | **있다** |
| `speak()` 가 실제로 시작되는가 | **`onstart` 가 떴다** |
| 한국어 목소리가 잡히는가 | **`ko-KR / Microsoft Heami`** (그 PC 기준 7개 중 하나) |

도구: `.scratch/_board.mjs`(구조·음성 동시 측정) · `.scratch/_boardsrc.mjs`(원본 스크립트 추출).

---

## 붙일 자리 — 이미 다 마련돼 있다

전광판은 **새 호출이 들어온 순간에만** `blink()` 를 부르고 거기서 `chime()`(딩동)을
울립니다. 음성도 **바로 그 자리**에 붙습니다 — 새 판정 로직을 만들 필요가 없습니다.

```js
var isNew = key !== lastNo;
lastNo = key;
...
if (isNew) blink();        // ← 여기
```

그리고 **「소리 켜기」 버튼(`#sound`)이 이미 있습니다.** 브라우저는 사용자가 한 번
누르기 전에는 소리를 막는데, 그 관문을 전광판이 이미 통과하고 있습니다. 음성도 같은
버튼에 얹으면 **매장에서 외울 것이 늘지 않습니다** — 아침에 전광판을 켜고 「소리 켜기」를
한 번 누르는 것, 지금과 똑같습니다.

## 넣을 코드

### ① 상태 변수 — `var lastNo = '', fails = 0, ...` 줄 **바로 아래**

```js
/* ── 호출 음성안내 (2026-08-30) ─────────────────────────────────────────
 * 딩동(chime)과 같은 자리에서, 같은 조건으로 운다.
 * spokenAt 은 "이 번호는 이미 읽었다"는 표시 — 5초마다 도는 polling 이
 * 같은 호출을 다시 읽지 않게 한다. */
var voiceOn = false, spokenAt = {}, firstRender = true, voiceQ = [];
```

### ② 소리 켜기 버튼 — `$('sound').onclick` 안, `chime();` **바로 뒤**

```js
    voiceUnlock();
```

### ③ 함수 셋 — `chime()` 함수 **바로 아래**에 통째로 붙여넣기

```js
/* 사용자가 한 번 눌러 준 그 순간에 음성도 함께 깨운다.
 * 소리 없는 한 마디를 미리 뱉어 두는 것이 관례다 — 이걸 안 하면
 * 정작 고객을 호출할 때 첫 마디가 조용히 삼켜지는 브라우저가 있다. */
function voiceUnlock(){
  try {
    if (!('speechSynthesis' in window)) return;
    var u = new SpeechSynthesisUtterance(' ');
    u.volume = 0; u.lang = 'ko-KR';
    speechSynthesis.speak(u);
    voiceOn = true;
  } catch (e) {}
}

/* 숫자를 어떻게 읽을 것인가.
 * 전광판이 보여주는 것은 **휴대폰 뒷 4자리**다(화면 아래에 그렇게 적혀 있다).
 * 1234 를 그대로 넘기면 음성이 "천이백삼십사" 라고 읽는다 — 사람은 그렇게 말하지
 * 않는다. 네 자리는 한 자씩 끊어 읽고(0 은 "공"), 그 밖의 값(대기번호 12 등)은
 * 그대로 넘겨 "십이" 로 읽게 둔다. */
function sayNum(v){
  var s = String(v == null ? '' : v).trim();
  if (!/^\d{4}$/.test(s)) return s;
  var W = ['공','일','이','삼','사','오','육','칠','팔','구'];
  return s.split('').map(function(d){ return W[+d]; }).join('');
}

/* 한 사람을 두 번 읽는다(사장님 지시). 앞 사람을 다 읽고 다음 사람으로 넘어가도록
 * 큐로 세운다 — 여럿이 한꺼번에 호출되면 말이 겹쳐 아무것도 안 들린다. */
function speakNext(){
  if (!voiceQ.length) return;
  var text = voiceQ.shift();
  try {
    var u = new SpeechSynthesisUtterance(text);
    u.lang = 'ko-KR'; u.rate = 0.95; u.volume = 1;
    /* 그 PC 에 한국어 목소리가 있으면 집어 준다 — 없으면 브라우저 기본에 맡긴다 */
    var vs = speechSynthesis.getVoices() || [];
    for (var i = 0; i < vs.length; i++){
      if (vs[i].lang && vs[i].lang.indexOf('ko') === 0){ u.voice = vs[i]; break; }
    }
    u.onend = function(){ setTimeout(speakNext, 500); };
    u.onerror = function(){ setTimeout(speakNext, 500); };
    speechSynthesis.speak(u);
  } catch (e) {}
}

function announce(list){
  if (!voiceOn || !('speechSynthesis' in window)) return;
  /* 지금 화면에 없는 번호는 기억에서 지운다 — 나중에 다시 호출되면 다시 읽어야 한다 */
  var cur = {};
  list.forEach(function(x){ cur[String(x.tail || x.no)] = 1; });
  Object.keys(spokenAt).forEach(function(k){ if (!cur[k]) delete spokenAt[k]; });

  /* 아직 안 읽은 번호만. 한꺼번에 여럿이면 앞에서 세 명까지만 읽는다 —
     그 이상은 말이 길어져 정작 다음 호출을 덮는다(화면에는 다 보인다). */
  var fresh = [];
  list.forEach(function(x){
    var k = String(x.tail || x.no);
    if (!k || spokenAt[k]) return;
    spokenAt[k] = 1; fresh.push(k);
  });
  fresh.slice(0, 3).forEach(function(k){
    var line = sayNum(k) + '번 고객님, 상담이 가능합니다.';
    voiceQ.push(line); voiceQ.push(line);      // 두 번 (사장님 지시)
  });
  if (fresh.length) setTimeout(speakNext, 800);   // 딩동(0.45초)이 끝난 뒤에
}
```

### ④ `render()` 안 — `if (isNew) blink();` 를 이렇게

```js
    if (isNew) blink();
    /* 전광판을 켜자마자(또는 30~90분마다 도는 자동 새로고침 직후) 이미 호출돼 있던
     * 고객을 다시 부르면 안 된다 — 그 사람은 몇 분 전에 불린 사람이다.
     * 첫 그림에서는 읽지 않고 "이미 읽은 것"으로만 표시해 둔다. */
    if (firstRender) list.forEach(function(x){ spokenAt[String(x.tail || x.no)] = 1; });
    else if (isNew) announce(list);
    firstRender = false;
```

그리고 `render()` 의 **`} else {`** 쪽(호출이 하나도 없을 때) 맨 아래에도 한 줄:

```js
    firstRender = false;
```

## 이렇게 하기로 한 이유 — 바꾸시려면 여기를 보세요

| 정한 것 | 왜 |
|---|---|
| **「소리 켜기」를 누른 뒤에만 말한다** | 브라우저가 사용자 조작 전에는 소리를 막는다. 이미 딩동이 같은 규칙으로 돌고 있어, **버튼 하나가 모든 소리를 켠다**는 것이 매장에서 헷갈리지 않는다 |
| **네 자리는 한 자씩 읽는다** | `1234` → "천이백삼십사" 가 아니라 **"일이삼사"**. 전광판이 보여주는 것이 휴대폰 뒷 4자리라 사람이 부르는 방식과 같아야 한다 |
| **켠 직후에는 안 읽는다** | 전광판은 30~90분마다 스스로 새로고침한다. 그때마다 이미 호출된 고객을 다시 부르면 **가짜 호출**이 된다 |
| **한 번에 세 명까지** | 여럿이 동시에 호출되면 말이 길어져 다음 호출을 덮는다. 화면에는 여전히 다 보인다 |
| **딩동을 없애지 않았다** | 소리가 먼저 시선을 끌고 말이 뒤따르는 편이 알아듣기 쉽다. 딩동 0.45초가 끝난 뒤(0.8초) 말이 시작된다 |

## 매장에서 확인할 것

1. 전광판을 열고 **「소리 켜기」를 한 번 누른다**(누르면 버튼이 사라진다).
2. 컨시어지 관리자에서 대기 고객을 **호출**한다.
3. 딩동 뒤에 **"일이삼사번 고객님, 상담이 가능합니다"** 가 **두 번** 나오면 된 것이다.

**소리가 안 나면** — 버튼을 눌렀는지, 그 PC·태블릿에 한국어 음성이 깔려 있는지
(윈도우: 설정 → 시간 및 언어 → 음성 → 음성 추가). 한국어 목소리가 없으면 영어 목소리가
한글을 읽어 알아듣기 어렵습니다.

## 아직 안 한 것

- **문구는 못 바꾸게 두었습니다** — 사장님이 정하신 `"○○○번 고객님, 상담이 가능합니다"`
  한 줄입니다. 매장마다 다르게 하려면 시트에 칸을 하나 두고 `api_board` 가 함께 내려
  주면 됩니다.
- **읽는 속도(`u.rate = 0.95`)** 는 조금 느리게 잡아 두었습니다. 매장이 시끄러우면
  0.9 까지 내려도 됩니다.

## 검증 — 살아 있는 전광판에 얹어 돌려 봤다

사본을 만들어 시험한 것이 아니라, **실제 전광판 지면을 띄우고 그 프레임의 `render()` 에
가짜 호출 데이터를 먹여** 진짜 코드와 맞물리는지를 봤습니다(`.scratch/_voicetest.mjs`).

```
OK: 살아 있는 전광판에 붙었다 (render 전역 함수 확인)
OK: 소리를 켜기 전에는 말하지 않는다 (딩동과 같은 규칙)
OK: 전광판을 켠 직후(첫 그림)에는 읽지 않는다
OK: 새 호출을 두 번 읽는다 — "일이삼사번 고객님, 상담이 가능합니다."
OK: 같은 호출을 polling 마다 되풀이하지 않는다
OK: 여럿이 호출되면 세 명까지 · 각각 두 번 · 순서대로 (6마디)
OK: 사라졌다 다시 호출되면 다시 읽는다
OK: 네 자리가 아니면 그대로 읽게 둔다 — "12번 고객님, 상담이 가능합니다."
OK: 화면도 그대로 그려진다
```

**검사를 만들며 두 번 헛돌았고, 둘 다 적어 둘 값어치가 있습니다:**

- **`window.speechSynthesis` 는 읽기전용이다.** 그냥 대입하면 조용히 무시돼 가짜 음성이
  안 먹고, 그러면 *"아무것도 말하지 않는다"* 로 보여 **멀쩡한 코드를 고장으로 읽는다.**
  `Object.defineProperty(window, 'speechSynthesis', { configurable: true, value: … })` 로 덮어야 합니다.
- **고정 시간으로 기다리면 안 된다.** 마디 사이가 0.5초라 여섯 마디면 3초가 걸리는데
  1.3초만 기다려 *"세 마디밖에 안 했다"* 로 읽었습니다. **큐가 빌 때까지** 기다려야
  합니다(이 저장소가 jsdom 검사에서 이미 데인 함정과 같은 종류입니다).
