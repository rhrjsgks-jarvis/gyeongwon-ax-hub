# 팀 전체 사용 데이터 집계 — Google Apps Script 설정 가이드

경원 AX 허브는 지금까지 사용 로그가 **각자 브라우저(localStorage)에만** 저장되고 있었습니다.
임원 시연에서 "실사용 데이터"로 효율성을 보여주려면, 팀 전체 로그를 한 곳(구글시트)에
모으는 웹훅을 켜야 합니다. 아래 순서대로 진행해 주세요. (2~3분이면 끝납니다)

## ⚡ 이미 배포하셨다면 — 건의사항 이메일 알림 추가만 하면 됩니다

전체 새로 설정할 필요 없이 아래 3단계만 하시면 됩니다:

1. 이미 만들어둔 스프레드시트 → **확장 프로그램 → Apps Script** 로 들어가기
2. 열려 있는 코드 전체를 지우고, 이 저장소의 최신 `docs/apps-script/Code.gs` 내용으로 통째로 교체
   (상단에 `FEEDBACK_EMAIL = 'rhrjsgks@gmail.com'` 로 알림 받을 이메일이 이미 설정돼 있습니다.
   다른 주소로 받고 싶으면 이 부분만 원하는 이메일로 바꾸면 됩니다.)
3. **배포 → 배포 관리** → 기존 배포 옆 연필(✏️) 아이콘 → 버전을 **새 버전**으로 선택 → **배포**
   (URL은 그대로 유지되므로 Vercel 환경변수는 다시 건드릴 필요 없습니다)

이렇게 하면 허브 어느 페이지에서든 우측 하단 💬 버튼으로 건의사항을 보낼 때마다
설정한 이메일로 알림이 옵니다.

## 1. 구글 스프레드시트 생성

1. https://sheets.google.com 에서 새 스프레드시트 생성
2. 이름은 원하는 대로 (예: "경원AX허브 사용로그")
3. 시트 탭 이름은 신경 쓰지 않아도 됩니다 — 스크립트가 자동으로 `logs`라는 시트를 만듭니다

## 2. Apps Script 붙여넣기

1. 스프레드시트 메뉴에서 **확장 프로그램 → Apps Script** 클릭
2. 기본으로 열려 있는 `Code.gs` 파일의 내용을 전부 지우고
3. 이 저장소의 `docs/apps-script/Code.gs` 파일 내용을 그대로 복사해서 붙여넣기
4. 상단 저장 아이콘(💾) 클릭해서 저장

## 3. 웹 앱으로 배포

1. 우측 상단 **배포 → 새 배포** 클릭
2. 유형 선택에서 톱니바퀴 아이콘 클릭 → **웹 앱** 선택
3. 설정:
   - **실행 사용자**: 나 (본인 구글 계정)
   - **액세스 권한이 있는 사용자**: **전체** (Anyone) ← 팀원들이 로그인 없이 전송해야 하므로 필수
4. **배포** 클릭 → 처음 배포 시 구글 계정 권한 승인 필요(본인 계정이므로 "고급" → "이동" 눌러서 진행)
5. 배포 완료 후 뜨는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec` 형태)을 복사

## 4. URL을 저에게 알려주세요

복사한 URL을 저에게 전달해 주시면, 제가 `lib/logEvent.ts`의 `GAS_URL`에 반영하고
관리자 대시보드가 이 시트 데이터를 팀 전체 집계로 보여주도록 연결하겠습니다.

## 참고사항

- **개인정보**: 저장되는 항목은 타임스탬프·모듈명·행동(page_view/search 등)·익명 세션ID·검색어 정도이며,
  이름이나 사번 등 개인 식별 정보는 로그에 포함되지 않습니다(레벨업테스트 응시 정보 등 다른 시트와는 무관).
- **재배포**: 코드를 나중에 수정하면 "배포 → 배포 관리 → 수정 아이콘 → 새 버전"으로 재배포해야
  변경사항이 반영됩니다(URL은 그대로 유지됨).
- **스프레드시트 접근 권한**: 이 시트는 사용자님 구글 계정 소유이므로, 필요 시 팀 관리자에게만
  공유 권한을 주는 방식으로 접근을 제한할 수 있습니다.
