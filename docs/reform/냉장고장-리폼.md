## robots 확인

**받기 전에 확인했고, 막힌 곳은 받지 않았다.**

| 호스트 | 판정 | 근거 |
|---|---|---|
| `www.samsung.com` | **허용** | 글로벌 `https://www.samsung.com/robots.txt` 의 `User-agent: *` 그룹이 막는 것은 **검색 결과 지면뿐**이다 — `/*/search/`, `/*/ai-search/`, `/sec/search/searchresultB2c/*`, `/sec/business/search/searchresult/*`. `/sec/buying-guide/` · `/sec/samsung-care-plus/ce/reform/` 는 어느 Disallow 에도 걸리지 않는다 |
| `images.samsung.com` | **허용** | 위 규격도 이미지 호스트. 인용한 6장 전부 HTTP 200 으로 실재 확인 |
| `www.samsungsvc.co.kr` | **허용** | `User-agent: * / Allow: /`, 막는 것은 `/*?q=` 하나뿐 |
| **`selc.co.kr`** | **금지** | `User-agent: * / Disallow:/` — **자동 수집 안 함** |
| **`delivery.selc.co.kr`** | **금지** | `User-agent: * / Disallow:/` — **자동 수집 안 함**. ③의 값은 2026-08-20 사용자 지시로 **사람이 지목된 지면만 열어 옮긴 저장소 사본**을 인용한 것이고, 이번 조사에서 그 호스트에 요청을 보내지 않았다 |
| **`downloadcenter.samsung.com`** | **금지** | `User-agent: * / Disallow: /` — 설치설명서 PDF 가 여기 있어 **인덕션 상판 두께 규격을 못 받았다**. 사람이 브라우저로 직접 열어야 한다 |
| `www.dacorkorea.com` | **허용** | `/robots.txt` 가 **HTTP 404**(파일 부재 = 제한 없음), 루트는 200. 데이코 후드 매뉴얼 확인에 썼다 |
| `api.samsungsvc.co.kr` | 허용(robots 404)이나 **인증 필요** | 후드 수리요금 API(`/svc/hpRecycleApi/svcRecycleList`)가 JWT 를 요구해 401 |

- **`/sec/robots.txt` 를 보지 말 것** — Akamai 가 403 을 준다. 글로벌 `www.samsung.com/robots.txt` 가 우리에게 적용되는 파일이다.
- **samsung.com 은 HTTP 200 이라고 지면이 있는 것이 아니다.** `/sec/buying-guide/install-guide/` 가 200 을 주는데 본문은 *"페이지를 찾을 수가 없어요"* 인 **소프트 404** 다. 실제 설치가이드는 **`/sec/buying-guide/`** 하나다(3.2MB, SSR 이라 curl 로 본문이 그대로 온다).
- **같은 안내표가 지면마다 다른 판으로 실린다 — 한쪽만 보고 "없다"고 판정하지 말 것.** 후드장 리폼이 그랬다: buying-guide 판에는 **문의 번호만**, 제품 지면 판에는 **금액만** 있어서 buying-guide 만 보고 *"금액이 없다"* 고 한 번 틀렸다. **품목 지면과 제품 지면을 둘 다 볼 것.**
- **치수가 `<img alt>` 안에 있는 경우가 많다.** 태그를 걷어내는 방식으로 본문만 뽑으면 **alt 가 통째로 사라진다** — 후드 패널 898 × 600mm 과 설치 높이가 전부 alt 안에 있었다. 규격을 찾을 때는 **원본 HTML 에서 alt 도 함께 훑을 것.**

**조합에서 반드시 지킬 것 (원문 그대로)**

- **프리스탠딩은 페어·키친핏 설치가 불가하다.** 프리스탠딩↔프리스탠딩, 프리스탠딩↔키친핏 페어 설치 모두 불가.
- **Infinite Line 은 4도어와 1도어 간 페어 설치가 불가하다.**
- **Infinite Line 1도어 조합**: 냉장고끼리·냉동고끼리 맞붙일 수 없고, **냉동고는 반드시 좌측 끝**에 설치.
- `4+4` 를 제외한 페어 설치에서 **힌지와 힌지가 맞닿는 배치는 불가**.
- `4+4` 는 맞닿는 도어의 오픈 각도를 **90도로 조정**해 동시 개폐 간섭을 막을 수 있다.
- **키친핏 Max 는 냉장고장 앞에 700mm 이상의 여유 공간**이 필요하다(장 안으로 밀어 넣어야 한다).
- 키친핏 Max 전면 VIEW 의 가로(냉장고 908mm · 김치 795mm)는 **최하단 양측면 돌출 구조물 각 2mm 를 뺀 값**이다.
- 도어를 끝까지 열었을 때 필요한 가로: **키친핏 Max 냉장고 1,157mm** · **김치플러스 Max 1,007mm** · `RF60*` 1,126mm · `RQ42*` 980mm.
- **사전 점검이 전제다** — 원문: *"사이즈, 후면 콘센트, 매립관 위치 등 설치 적합성 검토를 위해 설치기사의 사전 점검이 필요합니다."*

`size-reps.json` 의 4대 세트는 제품군 이름이 **`Infinite 1도어 키친핏 4세트`** 인데 계산은 **Bespoke Max 값(6mm / 4mm)** 으로 되어 있다(그 파일 주석도 *"간격은 신형 Bespoke 키친핏 Max 기준(구형 10㎜ 아님)"* 이라 스스로 밝힌다). 그런데 삼성닷컴 설치가이드는 **Infinite Line 1도어를 제품 간 10mm · 제품↔장 각 5mm** 로 적는다. 그 값으로 다시 계산하면 —

| | 제품 간 | 외곽 | 제품 폭 합 | 내경 가로 |
|---|---|---|---|---|
| 표의 값 (Bespoke Max 기준) | 6mm | 각 4mm | 2,398mm | 2,406mm |
| **Infinite Line 기준으로 다시 계산** | **10mm** | **각 5mm** | **2,410mm** | **2,420mm** |

**14mm 차이**다. 키친핏은 장 안에 끼우는 여유라 **작게 잡으면 안 들어간다** — Infinite Line 4대 세트 상담이면 **2,420mm** 로 보는 편이 안전하다. 다만 이 재계산은 설치가이드 본문 수치로 내가 유도한 것이지 삼성닷컴이 그 총폭을 적어 준 것이 아니므로, **확정 전에는 실측·판매처 확인이 필요하다.**
