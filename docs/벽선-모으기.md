# 벽선 모으기 — 매장이 잡은 벽선을 공용 목록으로

> 상담사용 안내 + 개발자 합치기 절차. 2026-08-19 기준 공용 목록 **12건**.

## 왜 이걸 하나

**도면 이미지 수집은 소진됐다.** 청약홈은 2021-10 이후만 조회되고, 그 전 단지는 분양
사이트가 사라졌다. 건설사 브랜드 지면도 준공 단지 평면도를 남기지 않는다. 관할
3,829개 단지 중 도면이 있는 곳은 **149곳**뿐이다.

그런데 **3D 배치에 정말 필요한 것은 도면 이미지가 아니라 벽 좌표**다. 도면은 벽 좌표를
얻는 수단일 뿐이고, 3D 에 들어가는 순간 이미지는 쓰이지 않는다.

그리고 **벽 좌표에는 저작권 제약이 없다** — 도면의 파생 측정값이기 때문이다. 그래서
`public/plan-library.json` 은 저장소에 담을 수 있고 배포본에 그대로 실린다.

**같은 주택형이면 벽이 같다.** 단지 하나당 주택형 3~5개만 있으면 그 단지 전체가
커버된다. 매장 몇 곳만 참여해도 관할 단지가 빠르게 찬다.

---

## 상담사가 하는 일 — 3단계

고객 도면을 한 번 잡아 두면, 그 단지는 **다음 배포부터 모든 매장이 도면 없이** 쓴다.

1. **방을 잡는다** — 배치 시뮬레이터에서 도면을 올리고 축척을 맞춘 뒤 `벽 자동 인식`.
   화면이 묻는 대로 **안방 가로 길이(mm)** 를 넣으면 도면 전체가 그 비율로 맞춰진다.
2. **`단지 저장`** — 단지명과 주택형을 적는다. 이 기기에 남는다.
3. **`단지 불러오기` → `벽선 보내기`** — 파일 하나가 만들어진다. 그것을 개발자에게 보낸다.
   (카톡·메일 무엇이든 된다. **도면 이미지는 담기지 않는다** — 방 경계 좌표뿐이다.)

`단지 불러오기` 시트가 *"이 기기에 저장해 둔 단지 N곳이 있습니다"* 라고 알려 준다.

### 꼭 지켜 주실 것

- **축척을 맞추지 않은 채로 저장하지 마세요.** 축척이 없으면 좌표가 mm 가 아니라
  그림 픽셀이라, 다른 매장에서 불러오면 **크기가 통째로 틀린 집**이 뜬다.
- **방 이름이 엉뚱한 자리에 붙었으면 고쳐 주세요.** 공용 목록에는 이미지가 없어서,
  받는 쪽에는 이름을 바로잡을 근거가 화면에 없다.
- 잘 모르겠으면 **그냥 보내 주세요.** 아래 관문이 걸러 냅니다.

## 개발자가 하는 일 — 합치기

```bash
npm run merge:library <받은파일.json> --dry   # 먼저 미리보기
npm run merge:library <받은파일.json>          # 담기
npm run test:library                          # 관문이 도는지
git add public/plan-library.json && git commit
```

**커밋해야 매장에 나간다** — 이 파일은 배포본에 그대로 실린다.

### 관문 — 무엇이 걸러지고 왜

쓰레기가 들어가면 그것을 불러온 **다른 매장 상담사가 틀린 치수로 상담한다.** 그래서
합치기 자체보다 거르는 쪽이 이 도구의 값어치다.

| 걸러내는 것 | 왜 |
|---|---|
| 이미지·base64 가 섞임 | 저작권. 공용 목록은 좌표만 담는다 |
| 벽 3개 미만 | 방이 성립하지 않는다 |
| 한 변 30m 초과 · 방 1~200㎡ 밖 | 축척이 틀어진 신호 |
| 단지·주택형 이름 없음 | 목록에서 못 찾는다 |
| 타입 숫자 대비 넓이 0.6~1.6배 밖 | 주택형 이름이 곧 전용면적이라 **바깥 자료 없이 검산된다**. `T1` 처럼 글자가 앞에 붙은 타입은 면적이 아니므로 이 검사를 건너뛴다 |
| 방 3곳 이상인데 가장 넓은 방이 거실이 아님 | 이름이 엉뚱한 자리에 붙은 것 |
| 이미 있는 단지·주택형 | 조용히 덮지 않는다. `--force` 로만 덮는다 |

**범위는 넉넉히 잡았다** — 목적은 "정확한 값 고르기"가 아니라 **"명백히 잘못된 것
거르기"** 다. 좁히면 멀쩡한 것을 막는다.

## 길이 셋이다 — 그리고 셋 다 사람 손이 든다

### ① 매장이 보내 주는 것 (주력)

위의 3단계다. 상담 한 번이 곧 벽선 한 벌이 된다.

### ② 이용허락이 열린 공공 도면을 개발자가 손질하는 것

**LH 「주택 평면도 현황」**(공공데이터포털, 이용허락 제한 없음)은 치수가 100% 인쇄돼
있어 축척을 자동으로 읽을 수 있다. 다만 **경원 관할은 하남 6장이 전부**라 이 길로
더 나올 것은 없다 — 2026-08-19 에 그 6장을 전부 담아 **소진했다.**

**자동으로 끝까지는 안 된다.** 6장 전수에서 결함이 **한 종류로 모였다**:

| 무엇이 | 왜 |
|---|---|
| `현관 11.1㎡` 처럼 **바깥이 방으로** 잡힌다 | 문이 열린 채 그려져 **현관에서 도면 바깥으로 샌다.** 이름은 "가장 작은 포함 다각형"에 붙으므로 그 샌 다각형이 현관 글자를 품어 이름까지 달고 들어온다 |
| 도면 여백의 **빈 상자** | 치수선 바깥 흰 자리가 닫힌 영역으로 잡힌다 |
| 같은 방이 **두 번** | 닫기 반경이 달라 큰 것·작은 것이 함께 남는다(넓이비 0.6 조건에 안 걸리는 경우) |
| 인쇄된 이름을 **OCR 이 못 읽음** | 도면 글자가 작다. 6장에서 27종 목록으로 읽힌 것은 절반뿐이었다 |

그래서 **번호를 찍어 겹쳐 보고 손으로 확정한다**(장당 5분):

```bash
node .scratch/lh-overlay2.mjs        # 다각형마다 번호를 모서리에 찍어 도면에 겹친다
#  → 눈으로 보고 .scratch/lh-curate.mjs 의 손질표(drop·name)를 적는다
node .scratch/lh-curate.mjs          # 표를 적용 → .scratch/lh-entries-final.json
npm run merge:library .scratch/lh-entries-final.json --dry
```

- **번호는 다각형 모서리에 찍는다** — 가운데 놓으면 도면에 인쇄된 방 이름을 덮어
  정작 확인해야 할 글자가 안 보인다.
- **지어내지 않는다.** 도면에 이름이 인쇄돼 있지 않은 자리는 `공간N` 그대로 둔다.
  통로를 '복도'라 부르는 것은 읽은 것이 아니라 지은 것이다.
- **관문이 실제로 물었다** — 손질 전 59B 는 합계가 전용면적의 **1.87배**였다(바깥 여백
  두 곳 54㎡). 손질 뒤 0.99배. 출처 문구에 파일명을 적었더니 `.png` 때문에
  "이미지가 섞여 있다"로 6건 전부 걸리기도 했다 — **관문을 느슨하게 하지 말고
  적는 쪽을 고칠 것.**

**여기서 자동으로 더 늘릴 수는 없다.** 색인 696장 중 축척이 확정된 것은 **12장뿐**
(치수가 인쇄된 도면이 8%다)이고 그 12장은 이미 다 처리했다 —
`node .scratch/seed-library.mjs` 를 다시 돌려도 **담기는 것은 0건**이다.
LH 도 하남 6장으로 끝났다. **그래서 앞으로 이 목록이 자라는 길은 ①과 ③ 이다** — 둘 다
사람이 화면을 보는 데서 시작한다.

### ③ 사람이 화면에서 보고 저장한 도면 (포털·카탈로그·고객 도면)

**부동산 포털은 자동 수집이 금지돼 있다** — 호갱노노 robots 는 *"express written
permission 없이는 크롤링 금지"*, 아실·KB부동산은 `User-agent: * → Disallow: /` 다
(2026-08-19 원문 확인). **브라우저를 띄워 클릭하는 것도 자동 접근**이라 같은 금지에 걸린다.

그런데 **사람이 화면을 보는 것은 별개**다. 그래서 이렇게 나눈다 —
**보는 것은 사람, 그 뒤 전부는 도구.**

```bash
# 1) 본 화면에서 도면을 저장해 이 폴더에 넣는다 (이름이 곧 단지·주택형이다)
#    .scratch/_intake/수원_광교호수마을참누리_84A.png
#    치수가 인쇄돼 있지 않으면 같은 이름의 .mm.txt 에 기준 벽 길이(mm) 한 줄
node .scratch/intake.mjs           # 축척 읽기 → 벽 인식 → 방 이름 OCR
node .scratch/intake-overlay.mjs   # 번호를 겹쳐 그린다 (모서리에 찍는다)
#    → 눈으로 보고 .scratch/intake-curate.json 에 뺄 것·이름을 적는다
node .scratch/intake-curate.mjs    # 손질표 적용 (관문에 걸릴 것을 미리 경고한다)
npm run merge:library .scratch/intake-final.json --dry
```

- **이미지는 저장소에 들어가지 않는다.** `.scratch/` 는 gitignore 대상이고, 커밋되는
  것은 좌표뿐이다. 3D 가 실제로 먹는 것도 좌표뿐이라 잃는 것이 없다.
- **축척이 없으면 만들지 않는다.** 인쇄된 치수를 읽거나(8%), 사람이 벽 길이 하나를
  적어 주거나, 둘 다 없으면 **건너뛴다.** 어림으로 채우면 "들어갑니다"가 거짓이 된다.
- 포털 자료를 **정식으로** 쓰려면 서면 허락을 받으면 된다 —
  요청문 초안은 `docs/포털-평면도-이용허락-요청문.md`.
