# 모바일 · 웨어러블 하이엔드 USP

> 출처: 삼성닷컴(www.samsung.com/sec) · 조사일 2026-08-31
>
> **여기 적힌 문장과 수치는 전부 삼성닷컴에서 직접 확인한 것이다.** 확인하지 못한 항목은
> 비워 두지 않고 각 절의 「확인 못 한 것」에 적었다 — 비워 두면 *"그런 사양이 없다"* 로 읽힌다.

## 이 문서를 읽는 법

- **「핵심 USP」의 굵은 문장은 삼성이 제품 목록 API(`uspDescList`)에 스스로 적어 둔 셀링포인트다.**
  상담사가 고객에게 그대로 읽어도 되는 문장이다.
- **「뒷받침 사양」은 지원 페이지(`support/model/{모델코드}/`)의 사양표 원문**이고, 마케팅
  수치(밝기·충전 속도·카메라 조리개 등)는 제품 상세 지면(PDP) 본문에서 가져왔다. 어느 쪽에서
  온 값인지 절마다 밝혀 두었다.
- **성능 점수(긱벤치 등)는 한 건도 싣지 않았다.** 이유는 문서 맨 아래 「싣지 않은 것」 참조.

### 조사 방법 (다시 조사할 때 그대로 쓸 것)

| 무엇 | 어디서 |
|---|---|
| 제품 목록 · 공식 USP 3줄 | `GET /sec/cxhr/pf/goodsList?dispClsfNo={번호}&sortType=10&page=1&rows=500` |
| **사양 수치** | **지원 페이지** `samsung.com/sec/support/model/{전체 SKU 코드}/` |
| 마케팅 헤드라인 · 카메라/밝기/충전 수치 | 제품 상세 지면(PDP) |

- **MX(폰·태블릿·워치·버즈)는 PDP 에 사양 블록이 없다.** 사양은 지원 페이지에서 받는다.
  반대로 **카메라 화소·조리개, 화면 밝기(nit), 충전 속도는 지원 페이지에 없고 PDP 본문에만** 있다.
  **두 곳을 다 봐야 한 제품이 채워진다.**
- 지원 페이지는 **접미까지 붙은 전체 SKU 코드**로 두드려야 200 이 온다(`SM-F976NZVIKOO`).
- 목록 API 의 `curPrice` 는 **조사 시점에 전 품목 `null`** 이라 이 문서에 가격은 없다.
