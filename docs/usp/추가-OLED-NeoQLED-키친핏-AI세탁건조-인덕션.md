  `User-agent: *` 가 막는 것은 `/*/search/` · `/*/ai-search/` · `/*/business/search/` 계열뿐이라 **위 세 경로는 모두 허용**이다.
- **curl 이 처음에 Akamai 차단 페이지(HTML)를 받았다.** `x-requested-with: XMLHttpRequest` 와
  `sec-fetch-*` · `User-Agent` 를 붙이자 정상 JSON 이 왔다. **브라우저는 필요 없다.**
- **`rows=500` 이 TV 에서는 빈 응답이다** — `count` 는 371 인데 `products` 가 0건이다.

- **묶음(패키지) SKU 는 뺐다** — 제품명에 `+` 가 있으면 조합 상품이다
  (예: `2026 OLED SH95 (209cm)+9.1.4ch 사운드바 Q930H`). OLED 는 93건 중 **29건만 단품**이다.

  **`인증기관` · `인증번호` · `인증구분` 은 남겼다** — 상담에서 근거로 쓰는 진짜 사양이다.
- **`pc-ver`/`mo-ver` 중복을 걷어냈다** — 같은 헤드라인이 두 벌 실린다(실측: 걷어내기 전 73건 → 후 42건).

추가로 **`같은 항목명이 그룹마다 있는`** 경우를 냉장고에서 실제로 만났다 —

묶음을 떼고 항목명만 읽으면 값이 뒤섞이므로 **그런 항목은 표에 묶음 이름을 앞에 붙였다.**
