# 노트북 · 모니터 · 주방가전 하이엔드 USP
> 출처: 삼성닷컴(www.samsung.com/sec) · 조사일 2026-08-31

상담사가 고객에게 **그대로 읽는 문장**을 모은 문서다. 아래 굵은 글씨 USP는 전부 삼성닷컴이
제품마다 공식으로 싣는 셀링포인트 문구를 **한 글자도 고치지 않고** 옮긴 것이고, 뒷받침 사양은
같은 지면의 사양표에서 온 값이다. **지어낸 문장·수치는 한 건도 없다.**

## 어떻게 모았나 (근거)

| 무엇 | 어디서 |
|---|---|
| 모델 목록 · USP 문구 | `GET /sec/cxhr/pf/goodsList?dispClsfNo={번호}&sortType=10&rows=500` 의 `uspDescList` |
| 사양표 (모니터 · 주방) | `GET /sec/xhr/pf/compGoodsSpecList?goodsIds={goodsId}` 의 `productsSpec` |
| 사양표 (갤럭시북) | 지원 페이지 `samsung.com/sec/support/model/{모델코드}/` |

- **갤럭시북은 PDP 에 사양 블록이 없다**(`spec` 이 붙은 id·클래스 0개). 그래서 사양은 지원 페이지에서 받았다.
- **USP 문구가 실제 화면에 그렇게 뜨는지 브라우저로 확인했다** — 인덕션 `CC99H63I1D` PDP 에서
  `uspDescList` 의 문구가 지면 제목(heading)으로 그대로 렌더되는 것을 확인했다. 전 제품이 같은 필드다.
- PDP 의 나머지 마케팅 설명은 **글자가 아니라 이미지**라 텍스트로 옮길 수 없었다(아래 「확인 못 한 것」).
- 법정 표시(`제조자/수입자`·`제조국`·`KC 인증 필 유무`·`동일모델의 출시년월`·`A/S 책임자와 전화번호`·`품질보증기준`)는 뺐다.
  단 **인덕션 상판 유리의 `제조사`(Schott 등)는 진짜 사양이라 남겼다.**

# 1. 갤럭시북 (노트북)

## ⚠️ 노트북 사양을 읽을 때 반드시 지킬 것

**CPU · 메모리 · 저장장치는 SKU 마다 갈린다.** `NT960XJG` 같은 기본 모델코드 하나가 여러 SKU 를
아우르고 그 셋이 정확히 SKU 마다 다르다. 그래서 아래 표는 **끝자리까지 붙은 전체 모델코드 기준**이고,
그 세 줄에는 `(이 SKU 기준)` 을 붙여 두었다.

**고객이 다른 구성을 물으면 그 SKU 코드로 다시 확인할 것** — 같은 기본코드의 형제 SKU 를 갈래마다 함께 적어 두었다.
반대로 **배터리 용량(Wh) · 무게 · 화면 크기·해상도**는 그 기본코드의 모든 SKU 가 공유하므로 안심하고 말해도 된다.

## 4-2. 갤럭시북

- **울트라(`NT960UJH-XC94Y`)를 뺀 세 모델은 지원 페이지에 `운영체제` 줄이 없다.** 제품명에 `Copilot+ PC` 가
  붙어 있고 목록 데이터가 `Windows 11 Home` 을 적지만, **사양표에서 확인된 것은 울트라뿐**이다.
- **CPU·메모리·저장장치는 이 문서에 적힌 SKU 에서만 맞다**(1장 머리말 참조).
- 프로 360 은 `외장 스토리지 지원 = MicroSD` 인데 울트라는 `SDXC` 다 — 규격이 갈리니 그대로 읽을 것.

## 4-3. 모니터

- **패널 공급사(QD-OLED / WOLED 등)는 사양표에 없다.** `패널 타입` 이 `OLED`·`VA`·`IPS` 로만 적힌다 —
  `스마트모니터 M9` USP 1번이 "QD-OLED패널"이라고 말하지만 **사양표에서 확인되는 것은 `OLED` 까지다.**
- `오디세이 3D G90XF` 의 **3D 지원 게임·콘텐츠 목록**은 사양표에 없다.
- `뷰피니티 S8` 은 **썬더볼트 5 · 140W** 로 확인됐지만, 그 포트로 **어떤 노트북이 충전되는지**(요구 전력)는 확인 못 했다.

## 4-4. 주방가전

- **`NV75T9879CD`(빌트인 오븐 75L)와 `NQ50T9539BD`(콤팩트 오븐 50L)는 삼성닷컴에 가격이 없다.**
  판매목록에는 있는데 `salePrice` 가 0 이다 — 설치·상담 상품이라 그렇게 보인다. **가격을 짐작해 말하지 말 것.**
- **인덕션 4종의 소음(dB) 수치가 사양표에 없다.** `간섭소음절감(DNC)` 이 "있음/없음"으로만 적힌다.
- **후드일체형(`CC99H84JAD`)의 후드 성능(풍량·소음)이 사양표에 없다.** 인덕션 쪽 사양만 실려 있다.
- `NZ64B9899RB` 는 **에너지소비효율 3등급**이다 — 같은 Infinite Line 이라도 1등급인 `CC99H84JAD`·`CC99H63I1D` 와 다르다.
  **"인피니트 라인은 1등급"이라고 뭉뚱그리면 그 자리에서 반박당한다.**

**모든 갈래를 채웠다.** 못 채운 것은 갈래가 아니라 **항목**이고 전부 4장에 적어 두었다 —
가장 큰 것은 ①PDP 이미지 안의 부연 마케팅 문구 ②오븐 2종의 가격 ③인덕션 소음(dB) 수치다.

## 다시 받는 법

```bash
# 1) 목록 + USP  (dispClsfNo: 갤럭시북 39120000 · 모니터 39030000 · 전기레인지 36070000 · 조리기기 36030000)
curl 'https://www.samsung.com/sec/cxhr/pf/goodsList?dispClsfNo=39030000&sortType=10&page=1&rows=500'
#    → products[].uspDescList / salePrice / goodsId / goodsDetailUrl

# 2) 사양표 (모니터·주방) — goodsId 는 1) 에서 얻는다
curl 'https://www.samsung.com/sec/xhr/pf/compGoodsSpecList?goodsIds=G000308039'
#    → productsSpec[].dispNm1(그룹) / dispNm2(항목) / specValue1(값)

# 3) 사양표 (갤럭시북) — PDP 에는 사양이 없다
curl 'https://www.samsung.com/sec/support/model/NT960UJH-XC94Y/'
#    → <strong class="spec-title">항목</strong><p class="spec-desc">값</p>
```

- **한글이 들어가는 요청은 node 스크립트로 할 것** — Git Bash 의 curl 은 CP949 로 인코딩해 깨진다.
- 목록 API 는 `curPrice` 가 아니라 **`salePrice`** 가 실제 가격이다(`curPrice` 는 전부 null).
- `rows=500` 이면 카테고리 전체가 한 번에 온다(`count` 와 일치하는지 확인할 것).
