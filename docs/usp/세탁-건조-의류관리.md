# 세탁 · 건조 · 의류관리 하이엔드 USP

> 출처: 삼성닷컴(www.samsung.com/sec) · 조사일 **2026-08-31**
>
> **이 문서의 모든 USP 문장은 삼성닷컴 제품 상세 지면(PDP)에서 실제로 확인한 것이다.**
> 확인하지 못한 항목은 「확인 못 함」이라고 적었다. 지어낸 문장은 한 건도 없다.
> 상담사가 고객에게 **그대로 읽는 문장**이므로, 아래 「검증 필요」 표시가 붙은 문구는
> 반드시 그 단서(각주)까지 함께 읽을 것.

## 조사 방법 (재현 가능)

| 무엇 | 어디서 |
|---|---|
| 모델 목록 · 대표 USP 3줄 | `GET /sec/cxhr/pf/goodsList?dispClsfNo={번호}&sortType=10&page=1&rows=500` → `uspDescList` |
| 마케팅 헤드라인 전체 | PDP HTML 의 `h2.title.pc-ver` |
| 헤드라인 설명문 | PDP HTML 의 `p.desc.pc-ver` |
| **각주(단서 조항)** | PDP HTML 의 `p.disc.pc-ver` |
| 사양표 | `GET /sec/xhr/pf/compGoodsSpecList?goodsIds={goodsId}` → `dispNm1`(묶음)·`dispNm2`(항목)·`specValue1`(값) |

- **사양은 브라우저 없이 받을 수 있다.** PDP 의 「스펙」 길잡이를 눌러야 생기는 `#compGoodsSpec`
  대신 위 사양 API 를 쓰면 결제 블록 오염도, 탭 병합 문제도 없다(goodsId 하나 = 제품 하나).
- **법정 표시는 뺐다** — `제조자/수입자` · `제조국가` · `KC 인증 필 유무` · `동일모델의 출시년월` ·
  `A/S 책임자와 전화번호` · `품질보증기준`.
- 목록 API 의 `curPrice` 는 **전 품목 null** 이다. 가격은 `salePrice` 를 읽었다(삼성닷컴 판매가).

# ⚠️ 먼저 읽을 것 — 「국내 최대 용량」의 진짜 범위

**삼성닷컴의 「국내 최대」 주장은 예외 없이 「세탁 용량」에만 걸려 있다. 건조 용량에는 한 번도 걸려 있지 않다.**

### 🔴 검증 필요 — 상담에서 이렇게 읽으면 반박당한다

목록 API 가 `WD90H25AHS` 의 대표 USP 를 이렇게 준다:

> **"세탁 25kg, 건조 20kg 국내 최대 용량"**

**이 문장은 「건조 20kg 도 국내 최대」로 읽힌다. 그렇게 읽으면 사실이 아니다.**

- LG **트롬 AI 오브제컬렉션 워시콤보 `FC2521SX6C`** 가 **세탁 25kg · 건조 21kg** 이다
  (저장소 `public/compare-app.html` 의 LG 베스트샵 카탈로그 대조값).
- 즉 **건조는 LG 가 1kg 더 크다.** 삼성 PDP 본문 헤드라인도 건조에는 「최대」를 붙이지 않고
  `넉넉해진 용량만큼 더욱 커진 편리함 세탁 25kg, 건조 20kg` 이라고만 적는다 — **PDP 가 더 정확하다.**
- **세탁 25kg 는 LG 도 25kg 라 「최대」는 동률이다.** 「우리만」이 아니라 「가장 큰 축에 든다」로 읽어야 한다.

**상담 권장 표현** — 「세탁 용량은 국내 최대 25kg 급입니다」(각주 범위 그대로).
**쓰지 말 것** — 「건조까지 국내 최대」 · 「국내 일체형 최대용량(건조 20kg)」.
> 저장소 이력: 「국내 일체형 최대용량(건조 20kg)」은 2026-08-03 LG 카탈로그 대조에서 성립하지
> 않는 것으로 확인돼 타사비교 셀링포인트에서 이미 삭제됐다(현재 소스에는 삭제 경위 주석만 남아 있다).

**`WD99F25AHR`(건조 18kg)에도 같은 주의가 적용된다** — 대표 USP 가
`국내 최대 용량으로 건조까지 빠르게 쾌속 코스 79분` 이라 「건조가 국내 최대」로 오독될 수 있으나,
각주는 **세탁 25kg** 만 근거로 든다.
