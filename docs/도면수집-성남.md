## 어떻게 하나 — 사용자님 몫은 30초입니다

1. 보시는 화면(포털·단지 홈페이지·고객이 준 도면)에서 **주택형 평면도를 저장**합니다.
2. 파일 이름을 **`시_단지명_주택형`** 으로 바꿔 `.scratch/_intake/` 에 넣습니다.
   - 예: `성남_엘리프세곡리버파크_84A.png`
   - 도면에 치수가 인쇄돼 있지 않으면 같은 이름의 `.mm.txt` 에 **벽 하나의 실제 길이(mm)** 를 적어 주세요(안방 가로가 보통 3,000~3,600).
3. 나머지(축척·벽 인식·방 이름·검수·합치기)는 제가 합니다. **이미지는 저장소에 들어가지 않습니다.**

**한 단지에 주택형 3~5개**면 충분합니다 — 같은 주택형이면 벽이 같아 그 단지 전체가 덮입니다.
